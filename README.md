# Zephyrus — Personal Portfolio

Zephyrus is a Matrix-inspired developer portfolio built with React and Vite. It uses animated digital rain and a terminal-inspired interface to present the developer's background, skills, selected projects, and contact links.

## Demo & Preview

- **Live portfolio:** https://mhazeemshafi.github.io/HazeemPortfolioV2/
- **Repository:** https://github.com/MHazeemShafi/HazeemPortfolioV2

## Features

- Matrix-inspired dark interface with green accents
- Animated digital-rain background
- Terminal-inspired presentation
- About and education sections
- Skills, projects, and contact links
- Responsive layout for different screen sizes

## Built With

- React
- Vite
- JavaScript
- CSS
- HTML5

## Requirements

- Node.js (LTS recommended)
- npm
- Git

## Installation

```bash
git clone https://github.com/MHazeemShafi/HazeemPortfolioV2.git
cd HazeemPortfolioV2
npm install
```

## Quick Start

Run the development server:

```bash
npm run dev
```

Vite prints a local URL in the terminal.

Build and preview the production version:

```bash
npm run build
npm run preview
```

Run the configured lint check:

```bash
npm run lint
```

## Configuration

The project uses Vite with the GitHub Pages base path `/HazeemPortfolioV2/`. No environment variables or API keys are documented as required.
